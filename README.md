# Reading log

A small installable web app for keeping a list of the books I've read, with when I read them, the author, and an open page per book for notes and quotes.

Plain HTML, CSS and JavaScript with no build step. Books are saved in the browser on each device; use Export/Import backup in the menu to move them.

Run locally: `python3 -m http.server 8000`, then open http://localhost:8000.
